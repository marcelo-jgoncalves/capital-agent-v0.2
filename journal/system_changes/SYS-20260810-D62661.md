# System Change: Context Management System

- Date/time: 2026-08-10T10:21:54-03:00
- Change ID: SYS-20260810-D62661
- Change class: A

## Problem observed

The repository had no formalized, AI-agnostic system for organizing hot/warm/cold context, no deterministic reconstruction of current state, no lightweight indexes for decisions/experiments/system-changes/approvals, and no single entry-point document letting a new AI operator discover canonical policy, state and history without relying on prior conversation memory.

## Evidence

Repository read in full during this session: `AI_OPERATING_MANUAL.md`,
`INVESTMENT_POLICY.md`, `CRITICAL_DECISIONS.md`, `EVALUATION_CRITIC_SYSTEM.md`,
`SYSTEM_EVOLUTION.md`, `HUMAN_GATES.md`, `ARCHITECTURE.md`, `ROADMAP.md`,
`config/*.json`, `data/ledger.csv`, `src/capital_agent.py`,
`tests/test_capital_agent.py`, and every directory listed in
`AI_OPERATING_MANUAL.md`'s required reading order. Confirmed: `experiments/`,
`journal/`, `evaluation/`, `approvals/` contained only templates/READMEs with no
decisions, experiments, approvals or post-mortems yet; `context/` did not exist;
no `CLAUDE.md` existed; `AGENTS.md` did not point to a single router. This is the
gap the change addresses.

## Proposed change

Added START_HERE.md (router) and CONTEXT_MANAGEMENT.md (hot/warm/cold layers and capture-to-archive lifecycle); added context/CURRENT_STATE.md generated deterministically by a new 'update-context' CLI command from config/policy.json, data/ledger.csv, experiments/active/, journal/decisions/, journal/system_changes/ and approvals/pending/; added context/knowledge/{lessons,recurring-errors,successful-patterns,rejected-opportunities,open-questions}.md; added context/indexes/{decisions,experiments,research,system-changes,approvals}.json with automatic append-on-create wiring in the propose/new-experiment/propose-system-change/request-approval CLI commands; added context/summaries/{weekly,monthly,strategies}/ and context/snapshots/ scaffolding; added CLAUDE.md as a thin adapter and updated AGENTS.md to route through START_HERE.md; initialized git version control for the repository as a rollback mechanism; added tests for update-context and index-append behavior.

## Expected benefit

Any capable AI can now start from START_HERE.md, read a small deterministic CURRENT_STATE.md instead of reconstructing state by hand, and find prior decisions/experiments/system-changes/approvals via flat JSON indexes without loading full journal history. No canonical policy was duplicated into adapters; no financial authority, risk limit or human gate was changed.

## New risks introduced

- A generated file (`context/CURRENT_STATE.md`) could drift from source data if
  someone hand-edits it instead of regenerating it. Mitigated: the file itself
  says "Do not hand-edit" and `update-context` overwrites it deterministically.
- Automatic index appends (`append_index`) could silently fail to record an
  entry if `context/indexes/` is absent. Mitigated: this is intentional
  (tolerant no-op for older checkouts, covered by
  `test_append_index_tolerates_missing_context_dir`) and the canonical record
  under `journal/`/`experiments/`/`approvals/` is written first and
  independently of index success.
- A new root file (`CLAUDE.md`) could be mistaken for a policy source by a
  future editor. Mitigated: it explicitly states it is not canonical and
  contains no policy content of its own.
